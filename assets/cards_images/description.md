Ниже представлено подробное описание каждой карточки в формате Markdown. Для обозначения специальных символов с карточек использованы эмодзи: 
*   🦎 — символ животного (ящерица)
*   🟥 — красная фишка еды
*   🟦 — синяя фишка еды

---

## 1. BURROWING / НОРНОЕ
*   **Иллюстрация:** Зверек, сидящий в подземной норе.
*   **Текст свойства:** Когда 🦎 ***НАКОРМЛЕНО***, оно не может быть атаковано хищником.
*   **Второе свойство (перевернуто внизу):** FAT TISSUE / ЖИРОВОЙ ЗАПАС

## 2. HIGH BODY WEIGHT / БОЛЬШОЙ
*   **Особые отметки:** В левом верхнем углу красный модификатор **+1** (увеличивает потребность в еде).
*   **Иллюстрация:** Зеленый динозавр (зауропод).
*   **Текст свойства:** 🦎 может быть атаковано только хищником со свойством БОЛЬШОЙ.
*   **Второе свойство (перевернуто внизу):** CARNIVOROUS / ХИЩНИК (с белым модификатором **+1**).

## 3. HIBERNATION ABILITY / СПЯЧКА
*   **Иллюстрация:** Большие зеленые буквы «Z Z z z», символизирующие сон.
*   **Текст свойства:** Можно использовать *в свою фазу питания* — 🦎 считается ***НАКОРМЛЕННЫМ***. Нельзя использовать два хода подряд и в последний ход игры.
*   **Второе свойство (перевернуто внизу):** CARNIVOROUS / ХИЩНИК (с белым модификатором **+1**).

## 4. PARASITE / ПАРАЗИТ
*   **Особые отметки:** В левом верхнем углу красный модификатор **+2** (значительно увеличивает потребность в еде).
*   **Иллюстрация:** Фиолетовый сегментированный червь-паразит.
*   **Текст свойства:** Можно сыграть только на 🦎 другого игрока.
*   **Второе свойство (перевернуто внизу):** CARNIVOROUS / ХИЩНИК (с белым модификатором **+1**).

## 5. COMMUNICATION / ВЗАИМОДЕЙСТВИЕ
*   **Особые отметки:** В верхних углах красные стрелки, указывающие влево и вправо (парное свойство).
*   **Иллюстрация:** Два муравья, контактирующие усиками.
*   **Текст свойства:** Сыграть одновременно на пару 🦎 🦎. Когда одно 🦎 получает 🟥 из «кормовой базы», другое 🦎 получает 🟥 вне очереди.
*   **Второе свойство (перевернуто внизу):** CARNIVOROUS / ХИЩНИК (с белым модификатором **+1**).

## 6. POISONOUS / ЯДОВИТОЕ
*   **Иллюстрация:** Череп рогатого животного с костью в зеленом круге.
*   **Текст свойства:** Хищник, съевший это 🦎, в *фазу вымирания* текущего хода погибает.
*   **Второе свойство (перевернуто внизу):** CARNIVOROUS / ХИЩНИК (с белым модификатором **+1**).

## 7. COOPERATION / СОТРУДНИЧЕСТВО
*   **Особые отметки:** В верхних углах красные стрелки, указывающие влево и вправо (парное свойство).
*   **Иллюстрация:** Две ящерицы, ползущие друг за другом по кругу.
*   **Текст свойства:** Сыграть одновременно на пару 🦎 🦎. Когда одно 🦎 получает 🟥 \ 🟦 - второе 🦎 сразу же получает одну 🟦.
*   **Второе свойство (перевернуто внизу):** FAT TISSUE / ЖИРОВОЙ ЗАПАС

## 8. SCAVENGER / ПАДАЛЬЩИК
*   **Иллюстрация:** Скелет животного, вокруг которого лежат кости.
*   **Текст свойства:** 🦎 получает 🟦, когда съедено другое 🦎. 🟦 получает только один ПАДАЛЬЩИК в игре, начиная с 🦎 владельца атаковавшего хищника, и далее по часовой стрелке. Нельзя сыграть на 🦎 со свойством ХИЩНИК и наоборот.
*   *Примечание:* На этой карточке нет перевернутого второго свойства снизу.

## 9. SYMBIOSIS / СИМБИОЗ
*   **Особые отметки:** В левом верхнем углу красная стрелка-указатель с надписью «СИМБИОНТ» (парное несимметричное свойство).
*   **Иллюстрация:** Крокодил с открытой пастью, в которой стоит птичка (крокодилов дантист).
*   **Текст свойства:** Сыграть одновременно на пару 🦎 🦎. Одно из 🦎 указывается как «симбионт». Другое 🦎 не может быть атаковано хищником, пока жив «симбионт», но может получать 🟥 \ 🟦, только если «симбионт» уже ***НАКОРМЛЕН***.
*   *Примечание:* На этой карточке нет перевернутого второго свойства снизу.
